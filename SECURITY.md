# Security and Privacy Policy

## Privacy Architecture
- All data stays in the browser. There is zero server-side processing of any user data.
- The only external network requests made are fetching map tiles from Carto's public basemap CDN (or a deliberately configured tile provider).

## External Network Requests
- The default style fetches raster tiles from `https://*.basemaps.cartocdn.com`.
- Map providers can infer the map areas requested through tile URLs. Timeline JSON, place names, searches, and exports are never sent to them.
- No other third-party APIs are called during runtime.

## Content Security Policy (CSP) Recommendations
The application is secured using the following Content Security Policy:
```http
Content-Security-Policy: default-src 'self'; script-src 'self'; style-src 'self' 'unsafe-inline'; img-src 'self' data: blob: https://*.basemaps.cartocdn.com; connect-src 'self' https://*.basemaps.cartocdn.com; worker-src 'self' blob:; font-src 'self'
```
This ensures that only authorized scripts and external connections (like OpenStreetMap tiles) are allowed.

## Contributor Guidelines
- **NEVER** add analytics, telemetry, or error-reporting tools that collect location data or personal information.
- Ensure all new features align with the offline-first and privacy-focused architecture of the application.

## Export Safety
- All data exports and downloads generated by the application are handled locally via blob URLs. No data is sent to a server to generate a download.

## Local Storage & IndexedDB
- Timeline persistence is opt-in. When enabled, normalized timeline data is stored locally on the user's device via IndexedDB.
- This data is completely controlled by the user and can be cleared at any time through their browser settings.
